# Canonical registries

This directory will hold RED's stable project registries.

Planned registries:

- species
- forms
- moves
- abilities
- items
- types
- evolution methods
- encounter tables
- trainer classes
- maps/scripts/text/graphics/audio resource keys

A registry ID is a project identity, not a ROM address, localized name, Pokédex
number, or an upstream C enum value.

Generation 10 entries are added only from verified source data. Existing IDs
must never be renumbered to make room for a later generation.
